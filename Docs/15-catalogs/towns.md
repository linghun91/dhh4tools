# 港口目录（eTown）

原版内容包。`NUM_TOWN=97`，`INVALID_TOWN=-1`。来源：World0 `GetFixTownProc`，`Docs/_data/towns_world0.json`，名称与 `srcdata/source/TownID.h` 一致。

坐标是城镇记录里的原版整数，**不是** `World.dat` 的 2500×2500 格子下标。换算公式未还原，当作「原版坐标单位」保存。`x1,y1` 与 `x2,y2` 是记录中的两点，两点各自含义 `[未知]`。

`is_capital` 来自城镇记录首都标记。`region` 字节 0–20，共 21 档；是否等于 `eCountry` / `eCulture` 未从 `CTown` 字段名确认 `[推断]`。21 个首都见 [04-id-registry.md](../00-overview/04-id-registry.md)。

特产品 5 槽是 `eTradingItem` ID，不是 `eItem`。空槽写 `empty`（原版 `0x6A=106`）。本表只列 ID；名称见 [trading-items.md](trading-items.md)。

World1 97 港中文名与 World0 **全部相同**（`Docs/_data/world1_names.json`）。

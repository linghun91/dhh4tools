World0 与 World1：97 港名、坐标、`is_capital`、`culture_id`、`remains_id`、5 个特产品槽**全同**；78 港只在 `+0x49..+0x55` 有字节差（`+0x48` u32、`+0x4C` 三对、`+0x52` 发展度），逐港见 [04-world0-world1-diff.md](../10-narrative/04-world0-world1-diff.md)。

坐标是城镇记录里的原版整数，**不是** `World.dat`（2500×1250 `uint16`）的格子下标。航行坐标 `/16`（向零）→ chip 下标 `[确认]`，港口坐标与航行坐标同一空间 `[推断]`（`01-world/01`、`13-algorithms/01`）；YAML 写 `coords: { space: original, … }`。

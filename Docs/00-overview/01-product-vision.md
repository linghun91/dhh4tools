# 产品愿景：把 DK4PK 拆成可配置的航海经营沙盒

## 这是什么

原作是光荣《大航海时代4 パワーアップキット》的 Steam HD 移植（DK4HD，2021）。六个（实际七个可选）主角剧本、97 座港口、全球贸易、舰队经营、海战与发现。

本 Docs 目录的重构目标：

> **保留原作玩法闭环，把全部内容与数值从代码里抽出来，使每一个系统都能单独改表、单独测、单独替换。**

不是新作设定集，也不是反汇编笔记。是给重制/模组化引擎用的设计规格。

## 原作要保住的体验

1. **选一个提督，从一座港出发**，用贸易差价滚雪球。
2. **船、人、货、炮、帆** 绑在同一支舰队上，出海就消耗补给与耐久。
3. **港口是节点**：交易所、造船厂、酒馆、公馆、公会、教会、宫殿、广场，各做一件事。
4. **海域是图**：风、潮流、发现、遭遇、黄金航路，把点连成线。
5. **势力在抢份额**：投资、特产品、合约、地方舰队、攻城，把贸易变成政治。
6. **剧本给动机**，沙盒给手段。事件是触发器，不是关卡墙。

## 重构后的产品形态

| 层 | 职责 | 可变性 |
| --- | --- | --- |
| 引擎运行时 | 场景、存档、模拟 tick | 代码，少改 |
| 系统模块 | 贸易、航海、战斗、人物… | 代码实现公式解释器 |
| 内容包 | World0/World1、剧本、事件脚本 | 纯数据 |
| 模组覆盖 | 加港、加船、改公式、改上限 | 覆盖 YAML |

玩家或模组作者应能在不重编 exe 的前提下：

- 加一座港口并挂上特产品与设施
- 改经验曲线、技能公式、市价弹性
- 换一套交易品，或把堆叠从 1 改到 99
- 加一个剧本，复用同一套世界表

## 明确不做

- 不在本文档里设计新 3D 渲染或 Steam 成就
- 不把 KTGL / D3D11 / ktsl2 音频算作玩法系统
- 不把原版 `/Od` `/RTC` 调试构建的实现细节当成设计约束（只当还原证据）

## 成功标准

1. 每个玩法系统有一份独立 YAML schema，字段都有来源。
2. 系统间只通过 ID 与事件通信。
3. 原版 97 港、235 人、105 交易品、231 道具、25 势力能作为「原版内容包」完整导入。
4. 改 `caps.yaml` 的等级上限，不必改贸易或战斗代码。

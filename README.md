# dhh4tools

《大航海时代4 威力加强版 HD》存档修改器。Windows 窗口程序，C11 + Win32 API，无第三方依赖。

## 功能

- **存档编辑**：读写 `Documents\KoeiTecmo\DK4HD\Savedata` 下的 `savedat00`–`savedat10`，修改主角和已招收海员的六维、等级、势力，保存时自动修正校验和。
- **游戏上限**：一次修改简、繁、日、韩四个语言版主程序的单段等级、基础属性、属性结算、技能和港口商业/军事上限。
- **商品堆叠**：同种商品叠在同一格，每格 1–255 件。左键操作 1 件，Shift + 左键操作整格。
- **流行品参数**：调整在交易所卖流行品时的占有率门槛、涨幅，以及给介绍信、推荐信所需的件数。
- **舰队亏损修正**：属性上限放开后，地方舰队买货不再出现巨额亏损。
- **备份与还原**：每次写入前自动备份，可一键还原原版主程序。

## 构建

需要 Windows 和以下任一编译器：

- [WinLibs MinGW-w64](https://winlibs.com/)（UCRT）：`winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT`
- Visual Studio（MSVC + Windows SDK）

在仓库根目录运行：

```bat
build.bat
```

生成 `dk4save.exe`。脚本优先用 gcc，没有 gcc 再用 MSVC，并自动编译 `src/` 下全部 `.c`。构建产物和运行时生成的 `dk4save.ini` 不进仓库。

## 使用须知

- 修改主程序前请完全退出游戏。
- 第一次写入时，原文件存为 `文件名.bak`，之后不再覆盖。以后每次写入前另存 `文件名.日期-时间-毫秒.bak`，每个文件只留最近 10 份。备份失败时不写入。
- "游戏上限"窗口里的"还原原版主程序"用 `.bak` 还原四个主程序，不影响存档。
- 存过堆叠货物的存档不要再用原版主程序读取：原版会把件数当作买入价的一部分。
- 舰队亏损修正只能阻止新的亏损，已经欠下的款项仍在存档里。

## 源码结构

```
src/
  main.c     程序入口
  common/    编译设置、字节读写、备份
  save/      存档格式与人物记录
  exe/       主程序读写、PE 解析、x64 机器码拼装
  patch/     主程序补丁：上限、代码洞、堆叠、流行品、舰队修正
  ui/        主窗口与"游戏上限"窗口
```

- 依赖只能向下引用：`ui → patch → exe / save → common`。
- 每个模块由一对 `.c` / `.h` 组成。头文件只放跨文件用到的接口，其余一律 `static`。`.c` 文件名在整个 `src/` 里不能重名。
- 新补丁放在 `patch/` 下，接入 `caps.c` 的 `read_exe_image()` / `patch_exe_image()`，输入框加在 `ui/cap_window.c`。
- 注释用简短中文，每个文件开头写明它负责什么。

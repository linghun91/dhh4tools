# dhh4tools

《大航海时代4 HD》存档修改器源码。窗口程序，读写 `Documents\KoeiTecmo\DK4HD\Savedata` 里的 `savedat00.dk4` 到 `savedat10.dk4`，也可改四个语言版主程序里的等级、属性、技能和港口商业/军事上限。

## 仓库里有什么

| 文件 | 作用 |
| --- | --- |
| `dk4save.c` | 全部源码（单文件，Win32 API） |
| `build.bat` | 构建脚本，优先 MinGW gcc，其次 MSVC |
| `dk4save.rc` | 资源脚本，把清单嵌进 exe |
| `dk4save.manifest` | Common Controls 6、DPI、长路径 |
| `mingw-endfile.specs` | gcc 链接时用的 specs，避免 WinLibs 默认 endfile 冲突 |
| `README.md` | 本说明 |
| `Docs/` | 大航海4 HD 重构设计文档（玩法、算法、可独立配置的表） |

没有第三方库。链接的是系统自带的 `comctl32`、`comdlg32`、`gdi32`、`user32`。

不进仓库的：`dk4save.exe`（构建产物）、`dk4save.ini`（运行时记下的游戏目录）、`.o` / `.obj` / `.res`（中间文件）。

## 构建

Windows。任选一套编译器：

1. [WinLibs MinGW-w64](https://winlibs.com/)（UCRT），或
   `winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT`
2. Visual Studio，带 MSVC 和 Windows SDK

在本目录运行：

```bat
build.bat
```

成功后会在本目录生成 `dk4save.exe`。改主程序前请完全退出游戏。

## 备份与还原

- 第一次保存存档、第一次写入主程序时，原文件存为 `文件名.bak`，以后不再覆盖。
- 之后每次写入前的文件另存为 `文件名.日期-时间-毫秒.bak`（例如 `DK4HD_sc.exe.20261030-153012-123.bak`），每个文件只留最近 10 份。
- 备份失败时不写入。
- “游戏上限”窗口的“还原原版主程序”用 `DK4HD_*.exe.bak` 把四个主程序还原成第一次写入前的样子；还原前的主程序同样另存一份。存档不受影响。

## 存档人物段与校验和

游戏从存档 `0x2C03` 起按人物 id 存 235 条记录：id 0–86 每条 25 字节（势力、六维、两段经验、HP、身心、装备），id 87–234 每条只有 2 字节（势力和一个只增不减的字节），他们的六维和经验不进存档。`0x35AA` 起是主角记录。

- 修改器只列出、只改 id 0–86 和主角。
- 存档头 `+0x18` 是正文各字段数值之和。保存时，修改器把改动字段的差值加到 `+0x18` 上，所以游戏存过的档改完后读档不再弹“所储存的进度有可能损坏了”。改动落在修改器不认识的字段上时拒绝写入。
- 2026-11-06 之前的版本按 `0x2C00` 起 98 行、每行 `0x19` 读写。第 0–86 行字段正好对上；第 87–97 行在存档里并不存在，改它们（尤其主角是拉斐尔时的批量修改）会把 id 88–219 的配角势力写成 255、196 或 0。那些版本也不重算 `+0x18`。
- 打开存档时如果发现配角势力越界，状态栏会提示。用同目录 `.bak` 里的原值恢复这些字节，再按差值修正 `+0x18`。

## 商品堆叠

“游戏上限”窗口的“同商品堆叠”可填 1 到 255（件数存在货物记录的一个字节里，所以最多 255）。填 1 还原原版。

- 交易所里这次买的同一商品先堆在同一格，满 N 件才再占一格。卖出、退货、全部卖出、撤回卖出和交易统计都按件数算。
- 按住 Shift 点市场商品，一次最多买 N 件；钱或舱位不够时买到为止。
- 价格栏放得下（不超过 6 个字符，如 `9x9999`、`99x999`）就显示一行“件数x单价”；放不下就分两行，上行“件数x”，下行单价。
- 存档里没有件数这个字节。写入后件数放在存档里买入价的最高字节里一起存、读，读档后还原。原版存档读进来每格都是 1 件。
- 玩家势力的舰队（地方舰队、下属 NPC 舰队）自动买货时，每格装到 N 件，载货量按“舱位 × N”算；自动卖货按件数结算。其他势力（别的商会、海盗等）的货物存法不同，保持原版。
- 委托、剧情、事件检查和扣除货物都按件数算。例如委托要 5 个红酒：一格堆了 30 个就算够，交付时这一格扣 5 个、剩 25 个；不够时从下一格接着扣，扣空的格子清掉。剧情送货仍是一格一件。
- 存过堆叠货物的存档不要再用原版主程序读：原版会把件数当成买入价的一部分。

补丁代码放在 `.text` 开头增量链接跳板表后面的 int3 空位里，开头写着 `DK4STK3`，末尾存着每个改动点的原版字节，填 1 或“还原原版主程序”时原样放回。旧版（上限 9 的 `DK4STK2`）写入的主程序会先被还原再写新版。

## 卖流行品

玩家在交易所确认交易时，这个城市的两种流行品按卖出件数影响占有率和介绍信/推荐信（堆叠补丁装上后就是件数，不是格数）。原版规则里的常数是按一格一件定的，“游戏上限”窗口里可以改：

| 输入框 | 原版 | 作用 |
| --- | --- | --- |
| 流行品门槛(每格) | 1 | 占有率不到 80 时，每种流行品要卖到 `舰队货舱格数 × 门槛 ÷ 2` 件（向上取整）才加占有率。填 0 表示卖一件就算 |
| 占有率涨幅除数 | 6 | 达到门槛后占有率加 `两种流行品件数 ÷ 除数 + 1`，游戏本身封顶 100 |
| 介绍信件数 | 10 | 占有率 80 以上，卖到这个数（到推荐信件数之前）给介绍信 |
| 推荐信件数 | 16 | 卖到这个数给推荐信；已有介绍信时升级成推荐信。必须大于介绍信件数 |

“按堆叠等比”按上面的堆叠数 N 填入 N、6N、10N、16N，一满格等于原版一格。“填入原版”填 1、6、10、16。

只改玩家自己在交易所卖货这一处（`CTrade::CommitDeal`），舰队自动交易不受影响。四个都是原版值时不写任何东西。补丁代码放在跳板表后 int3 空位的末尾（堆叠代码在开头），开头写着 `DK4FSH1`，末尾存原版字节，改回原版值时原样放回；和堆叠互不依赖，堆叠填 1 也能单独用。

## 地方舰队亏损修正

地方舰队和下属 NPC 舰队自动买货时，成本按 `货价 × (1000 − 船长交易能力 + 随机 0~99) ÷ 1000` 计算。原版能力最高 500，所以最多打五折。属性结算上限放开后能力会超过 1000，括号里变成负数，游戏再按无符号数相除，一次买货就记几百万支出，月报显示亏损上亿。

“写入主程序”每次都会顺带修正：这一处的能力先按 500 封顶再算，等于原版满能力。别处的能力值不受影响。四个语言版都用字节模式定位，补丁代码放在该函数结尾后的空位里。

已经亏出的欠账还在存档里：付不起的亏损会转到下个月支出，修正只能阻止新的亏损。最好读修正前、出问题之前的存档；或者解散该舰队，代价是身上的钱可能被扣光。
